# Reusable Knowledge

This directory contains cross-project intelligence. Store canonical entries in category subdirectories:

- `discoveries/` — potentially reusable observations
- `failures/` — failure modes, root causes, fixes, and prevention
- `decisions/` — reusable engineering decisions and trade-offs
- `patterns/` — repeatedly observed structures
- `rules/` — high-confidence actionable guidance

Create category files only when real verified knowledge is captured. Do not add placeholder claims. Every entry should use a stable ID and follow `templates/knowledge-entry.md` and `core/promotion-policy.md`.
