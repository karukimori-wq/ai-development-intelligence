# Evidence

Evidence anchors learned knowledge to verifiable reality.

Prefer compact evidence records over raw dumps. Suitable references include commits, pull requests, issues, tests, endpoint observations, authoritative documentation, and reproducible results.

Never store secrets, credentials, private connection strings, personal data, or unnecessary raw logs. Redact sensitive material and preserve only what is needed to establish the claim.

Use `templates/evidence.md` and `schemas/evidence.schema.json`.
